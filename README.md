# 🦜 라임이 통역기

우리 집 사랑앵무 라임이와 대화하는 재미용 통역 앱 (안드로이드)

## 기능
- **🎤 라임이한테 말하기**: 한국어로 말하면 라임이 소리로 바꿔 줌
  - 문장 분위기(인사·칭찬·간식·놀자·잘자·기타)에 맞는 라임이 녹음이 있으면 → 그 녹음 재생
  - 없으면 → 내 목소리를 높고 짧게 바꾼 지저귐 재생 (문장이 길수록 길게)
- **👂 라임이 말 듣기**: 라임이 소리의 길이·높낮이·크기·반복을 분석해 귀여운 한국어 문장으로 말해 줌 (재미용)
- **📋 라임이 소리 모음**: 녹음, 분위기 태그, 듣기, 이름·분위기 바꾸기, 삭제
- 대화 기록은 채팅방처럼 쌓이고, 모든 데이터는 폰 안에만 저장

## APK 만드는 법 (PC 없이 GitHub로)

1. **저장소 만들기**: GitHub 앱이나 github.com에서 `New repository` → 이름 `lime-translator` → Private 선택 → Create
2. **파일 올리기**: 압축을 푼 `LimeTranslator` 폴더 **안의 내용 전체**(`.github`, `app`, `build.gradle.kts` 등)를 저장소에 올림
   - 웹에서 `Add file → Upload files`로 폴더째 끌어다 놓으면 하위 폴더 구조가 그대로 올라감
   - 꼭 `.github/workflows/build.yml` 파일이 올라갔는지 확인 (점으로 시작하는 폴더라 빠지기 쉬움)
3. **빌드 확인**: 저장소의 `Actions` 탭 → `라임이 통역기 APK 빌드`가 자동 실행됨 (약 5~8분)
   - 자동으로 안 돌면 `Run workflow` 버튼으로 실행
4. **APK 받기**: 초록 체크가 뜬 실행 기록을 열고 맨 아래 `Artifacts`의 `LimeTranslator-apk` 다운로드 → 압축 풀면 `LimeTranslator.apk`
5. **설치**: 폰에서 APK 열기 → "출처를 알 수 없는 앱" 허용 → 설치
6. **처음 실행**: 마이크 권한 허용

> 항상 같은 서명 키(`app/lime.keystore`)로 빌드하므로, 고친 버전을 다시 빌드하면 기존 앱을 지우지 않고 덮어써서 설치됨 (녹음·기록 유지).

## 잘 안 될 때
- **음성인식이 안 됨**: Google 앱 최신 버전 설치, 설정 > 일반 > 음성 입력에서 Google 음성인식 선택
- **라임이 말이 소리 없이 글자로만 나옴**: 설정 > 일반 관리 > 텍스트 음성 변환에서 한국어 음성 데이터 설치
- **"동시 녹음이 안 돼서 합성 소리로 바꿨어요"**: 일부 폰은 음성인식 중 녹음을 막음 → 이때는 내 목소리 대신 순수 합성 지저귐 사용
- **라임이 소리가 '조용'으로 나옴**: 폰을 라임이 가까이 두고 다시 시도

## 구조
```
app/src/main/java/com/lime/translator/
  MainActivity.kt     권한 처리, 화면 전환
  LimeController.kt   음성인식·TTS·녹음·통역 흐름
  LimeBrain.kt        분위기 분류, 지저귐 합성, 소리 분석, 라임이 문장
  Audio.kt            마이크 녹음, WAV 저장, 재생
  Parrot.kt           라임이 캐릭터 그림·애니메이션
  Screens.kt          메인 화면, 소리 모음 화면
  Models.kt           데이터·저장
```
